# Freewheel product direction

## The job

Prepare at your desk, start a ride, then speak to two coding agents without looking at a screen. Every interaction must answer: who heard me, what are they doing, and do they need me?

## Interaction

- Two explicit wake phrases: Hey Puck and Hey Codex.
- Acknowledgement earcons, a short follow-up window, repeat, status, stop, and quiet commands.
- Concise audio responses: outcome, one important detail, next decision. Full transcript remains visible.
- Independent agents, project selection, resumable tasks, completion announcements, actionable failure states.
- Explicit approvals; no accidental “yes” from ambient speech. Read back actions with an approval number.
- Local credentials stay out of browser persistence and Git.
- Keep-awake is an owned, reversible caffeinate process, never a permanent system setting.

## Visual direction

A desk audio console. One broad listening surface, two distinct agent channels, a compact activity log. Avoid marketing sections, decorative icon grids, and artificial activity.

Palette: paper #f7f8fa; ink #202a37; secondary #66717f; line #dfe4ea; signal blue #285ee7; Amp amber #a96512.
Type: IBM Plex Sans for readable interface text and expressive large status. System monospace only for actual paths and technical excerpts.
Layout: left-aligned navigation and project controls; large central voice console; agent channels below; chronological activity on the right. Mobile stacks with the start/stop control always accessible.

```
Freewheel                     Session / Connections / Guide
---------------------------------------------------------
Workspace                     Session duration
[ speaking / listening instrument ]   [ Activity           ]
[ Start ride                      ]   [ Full task details   ]
[ Puck channel ] [ Codex channel  ]   [                    ]
```

The distinctive element is a restrained radial listening instrument, inspired by a wheel and an audio meter. It moves only when the session or real microphone level changes. Everything surrounding it stays quiet.
